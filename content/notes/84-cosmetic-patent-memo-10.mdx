## 発掘メモについて

## 2. 核心：USPTO／Espacenet 情報壁の構造

Day 22 引継ぎ (a) で「**USPTO/Espacenet 直接検索で avobenzone 1973 起点特許の番号を特定する**」アクションを取った。実行手順は以下：

```

  - Specialchem「Butyl Methoxydibenzoylmethane」
  - Wikipedia 英「Dibenzoylmethane」（親化合物）
  - PubChem CID 8433 Dibenzoylmethane
  - Givaudan SA Wikipedia 派生ページ・GlobalData 企業情報

[STEP 2] 1973 年起点特許番号の有無確認
  → 結果：上記 16 件いずれにも 1973 年起点特許の番号記載なし
  → Wikipedia 英 Avobenzone は本文に「Avobenzone was patented in 1973」の 1 行のみ
  → 同 Wikipedia 記事の引用 [36][37] の OpenURL は「rft.cc=US&rft.number=0」と
    番号フィールドが空欄の citation で、特定特許への直接リンクは含まれていない

[STEP 3] WebSearch で AI 生成候補番号を試行

  → 該当する人名 Lerch のヒットなし、Wikipedia の Avobenzone 一般情報のみ
  - 「Lifschütz Eucerit DRP 132307 154959 Wollwachsalkohol」検索
  → 番号情報なし、Wollwachsalkohol 専門サイトのみ
  - 「DE2354187 CH562252 US3920734 avobenzone dibenzoylmethane sunscreen 1973」検索
  → これらの候補番号の単独ヒットなし

    CH1851571A and CH1592074A, which correspond to the Swiss patents CH561168A5 and CH570454A5」

    関連ヒットなしで、AI（Search AI Overview と推定）の生成内容として実体検証不能

[STEP 4] patents.google.com 個別アクセス試行
  - patents.google.com/patent/CH561168A5 → WebFetch HTTP 503
  - patents.google.com/xhr/query?url=q%3DCH561168A5 → curl Captcha「Sorry... your
    computer or network may be sending automated queries」で全件拒否
  - patents.google.com/?q=Lifschütz&country=DE&before=publication:19031231 → 結果 0 件

[STEP 5] Espacenet REST API 試行
  - worldwide.espacenet.com/3.2/rest-services/publication-data/...
  → HTTP 403 Forbidden（API キー必須、認証なしアクセス拒否）

[STEP 6] 情報壁確定
  → USPTO Patent Public Search 対話検索（assignee=Roure Bertrand Dupont、

  → AI 生成候補番号は実体検証不能で採用しない（捏造リスク回避、
    feedback_source_no_fabrication 適用）
```

## 3. 化粧品サブシリーズ DB 形態 3 情報壁の構造的特徴（3 件目）

化粧品サブシリーズの DB 信頼性問題 4 形態のうち、**形態 3 情報壁** は本メモ CS-005 で **第 3 弾**として確定する。3 件並べると、情報壁の構造的特徴が明確になる。

| 共通要素 | CS-010（コウジ酸、Day 22 ep80） | CS-004（Eucerit、Day 23 ep83） | CS-005（avobenzone、本メモ） |
|---|---|---|---|
| 起点国 | 日本 | ドイツ | スイス／フランス（仏 Roure Bertrand Dupont、1991 年スイス Givaudan 統合） |
| 起点年代 | 1975-1988 | 1900-1902 | 1971-1973 |
| データベース壁 | J-PlatPat（JS-heavy / authenticated） | DPMA DEPATISnet（対話 UI 必須）+ 1900 年代カバレッジ薄 | USPTO Patent Public Search・Espacenet Worldwide Search（いずれも対話 UI / API 認証必須） |
| 旧公報体系 | 特公昭・特開昭 | DRP（Deutsches Reichspatent） | CH/FR/EP の 1970 年代旧公報 |
| 一次資料の歴史的事実 | 三省製薬・コーセー・厚生労働省で確認 | Beiersdorf・Wikipedia・独化学百科で確認 | DSM・dsm-firmenich・Wikipedia で確認（社名遷移含む） |
| 番号の不在 | J-PlatPat 公開公報番号 | DRP 番号 | CH/FR/EP/US の起点番号 |
| AI 生成候補の検証不能 | JP S58-118507 = Lion Corp 透明歯磨（番号取り違え発覚） | DRP 132307/154959/171146 = ヒットなし | CH561168A5/CH570454A5 = 単独ヒットなし |
| 次アクション | 三省製薬／J-PlatPat 対話検索 | DPMA 紙アーカイブ／Beiersdorf 社アーカイブ照会 | USPTO Patent Public Search／DSM 社直接照会 |

3 件並べてみると、**情報壁は国・言語・年代を問わず構造的に再現する**。Phase 1 化粧品サブシリーズが扱う **19 世紀末 - 20 世紀初頭の DRP / 1970 年代の CH-FR / 1980 年代の特公昭** という古い公報体系は、現代の Web ベース特許データベース（patents.google.com・worldwide.espacenet.com・USPTO Patent Public Search）の **対話的検索 UI / API 認証 / Captcha 防御**の壁を共通して持つ。

つまり、化粧品サブシリーズの DB 信頼性問題は **「歴史的事実は語られているのに、起点特許の番号だけが対話的検索 UI の向こうにある**」という構造的問題で、**個別の化粧品成分の問題ではなく、特許データベース体系の歴史的層構造の問題**として読む必要がある。

## 4. 厳密にはこう（簡略 3 項目）

**確認済みの事実：**
- avobenzone は butyl methoxydibenzoylmethane（INCI 名）、CAS 70356-09-1、商標 Parsol® 1789（PubChem CID 51040）。
- 1973 年に特許化（Wikipedia 英 Avobenzone「Avobenzone was patented in 1973」）。
- 1978 年 EU 承認、1988 年 FDA OTC 承認。
- 譲受人遷移は Roure Bertrand Dupont SA（仏）→ 1991 年頃 Givaudan-Roure 統合 → 2000 年 DSM Nutritional Products → 2010 年代以降 DSM（現 dsm-firmenich.com で Parsol® 1789 商標管理）。
- USPTO Patent Public Search・Espacenet Worldwide Search はいずれも対話 UI / API 認証必須。
- patents.google.com は 2026-05-09 時点で curl/WebFetch アクセスが Captcha「Sorry... your computer or network may be sending automated queries」で拒否される頻度が高い。

**未確認：**
- 1973 年起点特許の正確な番号（CH/FR/US/DE/EP のいずれか）。
- 発明者名（Wikipedia・PubChem・Pharmacompass・Smartskincare いずれも未記載）。
- AI 生成された候補番号（CH561168A5・CH570454A5・US3920734・DE2354187 等）は実体検証不能で採用しない。

**この比較が破綻する点：**
- 「Givaudan が 1973 年に発明」と書くと、**当時の社名は Roure Bertrand Dupont SA で、Givaudan と Roure の統合は 1991 年**という事実を見落とす。Givaudan SA（スイス、フランチンゲン）は 1796 年創業、Roure Bertrand Dupont SA（フランス、グラース）は別会社で、1991 年に Roche グループ内で統合され Givaudan-Roure になった。1973 年時点では別法人。
- 「avobenzone は UVA 吸収剤」と書くと、**現代の avobenzone は単独製品ではなく Tinosorb S・Mexoryl SX・Uvinul A Plus 等の他 UVA 吸収剤と組み合わせて使われる**事実を見落とす。avobenzone 単独は光不安定（UV 照射で分解、80% 以上が 1 時間で減衰）で、現代の sunscreen 製剤は **avobenzone + 安定化剤（octocrylene 等）+ 他 UVA 吸収剤の三層構造**が標準。
- 「FDA OTC 承認 1988 年」と書くと、avobenzone は 1988 年 FDA Final Monograph で sunscreen active ingredient として承認されたが、**2019 年 FDA 提案規則で GRASE（generally recognized as safe and effective）の再評価対象**に指定され、現在は安全性データ追加要請中。FDA 承認は静的な事実ではなく、規制再評価が継続している動的な状態。
- 「USPTO 情報壁」と書くと、USPTO が意図的に隠蔽しているような印象を与えるが、実態は **USPTO Patent Public Search の対話的 UI が curl/WebFetch では使えない**だけで、ブラウザでアクセスすれば 1971-1974 priority の Roure Bertrand Dupont 特許群は閲覧可能。情報壁は構造的なものであって、敵対的なものではない。
