Patent Archaeology 第1回（[ZISC](/notes/02-patent-archaeology-01)）では、30年前のIBM特許が現代NPUの設計図そのものだった話を書きました。

今回は時代をさらに100年さかのぼります。**1887年（明治20年）にニコラ・テスラが米国に出願し、1888年に成立した特許 US381968 を、Claude に4ページの仕様書＋4枚の図面ごと読ませてみました。**

## 結論を先に

**現在地球上で走っているEVのうち、駆動方式の系譜をまっすぐにたどると、その大半が1888年のニコラ・テスラの特許に行き着きます。**

公報番号：[US 381,968](https://patents.google.com/patent/US381968A/en)
タイトル：「Electro-Magnetic Motor」
発明者：Nikola Tesla（出願時の住所：N.Y.、出身：オーストリア＝ハンガリー領スミリャン）
出願：1887年10月12日
発行：1888年5月1日
譲渡：チャールズ・F・ペック（ニュージャージー州）に1/2譲渡
状態：**20世紀初頭にとっくにパブリックドメイン**

そしてこの特許の最大の皮肉は：

- **Tesla, Inc.（旧 Tesla Motors、2003年設立）の社名は、このニコラ・テスラへの献名**
- **Tesla 社のロゴ（縦の線）は、この特許に出てくる「銅ローター」のモチーフ**
- **初代Roadster（2008年）が採用した3相AC誘導モーターは、この特許のほぼ直系**
- **しかし Model 3（2017年〜）以降、Tesla は永久磁石モーター（IPM-SynRM）に主軸を移し、社名・ロゴの起源から少し離れていった**

「**社名とロゴはあるが、現役の駆動方式はもう半分別物**」という距離感を、138年前の特許文書から逆算して引き出すことができました。

## 1. 1件をどう選んだか

今回はリクエストベースで「テスラ関係」を起点にしたので、まずサブシリーズ判定から：

```
1. 「テスラ」と聞いて出てくる候補を、Patent / IR / Standard / Declassified
   それぞれで5件ずつ列挙
2. 各候補の「忘れられ度」と「現代との接続度」を5段階で自己評価
3. 一番乖離（忘れられ度 × 接続度）が大きいものを選ぶ
```

最終候補に残ったのは5件でした：

- **A. Nikola Tesla 1888年 AC モーター特許 US381968**（Patent #2）
- B. Tesla Autopilot HW1（Mobileye搭載期）特許群（Patent #2）
- C. Tesla Dojo D1 chip 特許（Patent #2）
- D. Tesla Master Plan Part 1（2006）の18年答え合わせ（IR #2）
- E. Tesla S-1（2010 IPO目論見書）の現在答え合わせ（IR #2）

A を選んだ理由は3つ：

- **「忘れられ度」が突出**：Nikola Tesla 本人の特許番号を即答できるエンジニアは、業界にもほぼいない
- **連載の幅が広がる**：Patent #1 が1995年（IBM ZISC）、#2 が1888年。100年以上のスパンが連載に厚みを出す
- **Tesla社という現代との橋がある**：「忘れられた長文」が「いま走っているEV」につながる、AI考古学らしい翻訳の余地が最大

## 2. 特許の正体（Claude に読ませた結果）

WebFetch で Google Patents から US381968 を取得し、Claude に投げた最初のプロンプトはこれです：

```
この特許（US381968）の以下を全部抽出してください：
1. 正確なタイトル
2. 発明者の氏名・出身・住所
3. 出願日・成立日
4. 譲渡先（assignee）
5. クレーム数
6. テクニカル・アブストラクト（発明の要旨）
7. 中核となる技術原理を3-5項目に箇条書き
8. polyphase / induction / alternating current / rotating magnetic field
   への言及があれば該当箇所
9. 主要な図面の構成
10. 仕様書の長さ（カラム数・ページ数）
特に印象的な箇所は2-3文を verbatim で引用
```

返ってきた要約のうち、私が背筋を冷やした verbatim 引用がこれです：

> "A motor is employed in which there are two or more independent circuits through which alternate currents are passed at proper intervals... for the purpose of effecting a progressive shifting of the magnetism..."

> "The disk D, owing to its tendency to assume that position in which it embraces the greatest possible number of the magnetic lines, is set in rotation, following the motion of the lines..."

訳すと：「2つ以上の独立した回路に、適切な間隔で交流電流を流すことで、磁極が連続的に移動する効果を作る」「ディスクDは磁力線をできるだけ多く取り込もうとする性質があるため、磁力線の動きに追従して回転する」。

これは現代の回転磁界（rotating magnetic field）と3相AC誘導モーターの原理を、1887年の英語でほぼそのまま述べています。

中核技術として Claude が抽出した5項目：

- 位相のずれた多相交流電流による、磁極の連続的な移動
- 2つ以上の独立した励磁回路の同期動作
- 整流子（commutator）を使わない、発電機〜モーター間の直結
- モーター速度と発電機速度の同期
- 通常負荷範囲内における定速動作

## 3. なぜ「気持ち悪いほど近い」のか — 138年の翻訳表

US381968 の technical mechanism を、現代のEVモーター用語に翻訳するプロンプトを投げました：

```
この特許の technical mechanism を、2026年現在のEVモーター技術者が
日常的に使っている用語に翻訳してください。
特に、各構成要素が現代モーターのどの概念に相当するか、
表形式で対応関係を示してください。
```

返ってきたのがこれです：

| US381968（1888年） | 現代EVドライブユニット |
|---|---|
| Two or more independent circuits with alternate currents | **3相交流（U/V/W相）** |
| Progressive shifting of magnetism | **回転磁界（Rotating Magnetic Field）** |
| Without commutator / brushes | **ブラシレス駆動** |
| Disk armature following the magnetic lines | **誘導モーターのローター（squirrel-cage rotor）** |
| Synchronism between motor and generator | **同期モーター（PMSM）の原理** |
| Constant speed under varying loads | **インバータ制御による定速・可変トルク** |

「**現代の3相AC誘導モーターの基本原理は、1888年にニコラ・テスラがほぼ全部書いていた**」と言ったら、自動車工学の人は怒るかもしれません。怒る人は、この特許を読んでいないのです。

特に「**整流子なしで、多相交流の位相差だけで磁界を回す**」という1行は、**Tesla Roadster（2008年）が採用した3相AC誘導モーターの設計思想と完全に同じ**です。

## 4. Tesla社が離れていった先

Wikipedia の Tesla, Inc. を読み込んで、Claude にこう聞きました：

```
Tesla 社が初代Roadsterから現行Modelシリーズまでに、
モーター方式をどう変えてきたか時系列で整理してください。
Nikola Tesla の1888年特許との距離感も評価してください。
```

返ってきた整理：

| 時期 | 車種 | モーター方式 | US381968との距離 |
|---|---|---|---|
| 2008-2012 | Roadster | **3相AC誘導モーター** | 直系 |
| 2012- | Model S | AC誘導（前後とも） | 直系 |
| 2015- | Model X | AC誘導（前後とも） | 直系 |
| 2017- | Model 3 | 前：AC誘導／**後：IPM-SynRM（永久磁石）** | **後輪は別系統に** |
| 2020- | Model Y | 前：AC誘導／後：IPM-SynRM | 同上 |

IPM-SynRM（Interior Permanent Magnet Synchronous Reluctance Motor）は、**永久磁石を使う同期モーター**です。これは Nikola Tesla の AC誘導モーターとは別の系譜で、日本では1990年代から東芝・三菱が量産技術を確立した分野です。

つまり、**Tesla社は2017年のModel 3で、自社の名前の由来である「Nikola Teslaの設計」から半分離れた**ことになります。Model 3/Y の主力駆動である後輪は、もはや US381968 の直系ではありません。

これは責められる選択ではありません。永久磁石モーターは効率が高く、低速トルクで有利です。EVに向いているのです。**ただ、社名とロゴの根拠から距離が開いた事実は、特許文書を読まないと見えません**。

## 5. AI考古学的な意味

ZISC（1995）と US381968（1888）を並べると、本連載の一つの法則が見えてきます。

**「ある技術が世間で『最先端』と呼ばれているとき、その設計図はたいてい数十年〜100年前のパブリックドメイン文書の中にもう書かれている。違いは、誰がそれをいま読み直すかだけ」**

US381968 は、機械学習や半導体の文脈で語られることが極端に少ない特許です。EV業界の人すら、Nikola Tesla の特許番号を読んだことがある人は珍しい。でも、彼らが毎日設計しているモーターの基本原理は、この4ページの仕様書に全部書いてあります。

LLM登場以前は、19世紀英語の特許文書をいちいち読み解く時間コストが、現役エンジニアには合いませんでした。**LLMが来たことで、4ページの古英語仕様書を5分で読めるようになった**。これが個人レベルで「忘れられた長文」を発掘できる理由です。

## 6. 落とし穴（今日ハマったもの）

**落とし穴1：Nikola Tesla の特許は4本セット**

US381968 / US381969 / US382279 / US382280 — 同時期に成立した4本がほぼ一塊で「テスラのAC誘導モーター特許」を構成します。LLMに「Nikola Tesla の AC モーター特許」とだけ聞くと、4本を混ぜて回答する事故が起きます。**特許番号を必ず1本に絞って投げる**のが鉄則です。

**落とし穴2：ガリレオ・フェラーリスとの優先権**

イタリアの物理学者ガリレオ・フェラーリスは、Tesla より早い1885年に多相誘導モーターの動作モデルを発表しています（公式論文は1888年4月）。**「AC誘導モーターを発明したのはTeslaか」という問いには、慎重な回答が必要**です。Westinghouseは1888年にTeslaの特許をライセンスする一方、フェラーリスの概念にもオプションを買っています（Wikipedia "Induction motor"）。

LLMに「テスラがAC誘導モーターを発明した」と書かせると、フェラーリスの存在を省略する事故が起きやすい。**これは捏造に近い省略で、AI考古学では避けるべき**です。

**落とし穴3：「Tesla」表記の二重性**

記事を書くとき、「Tesla」と書いただけでは Nikola Tesla（人物）と Tesla, Inc.（会社）どちらを指すか曖昧になります。私はこの記事で意図的に「ニコラ・テスラ」「Tesla社」と書き分けました。LLM下書きでは混同が頻発するので、執筆時点で表記ガイドを与える必要があります。

## おわりに

Nikola Tesla がこの特許を出願したのは1887年10月、彼が31歳のときです。アメリカに渡って3年目、英語もまだ片言だったはずの時期に、4ページの仕様書と4枚の図面で、現代のEV駆動系の原理を書ききっています。

138年経って、彼の名前を冠した会社が世界中の道を走っています。社名もロゴも、彼の特許に由来する。けれど、その会社のいちばん新しいクルマの後輪は、もう彼の設計ではありません。

「**Nikola Tesla の特許文書は、いま誰が一番熱心に読み返しているか**」と聞かれたら、答えは「Tesla社のエンジニアではなく、中国の比亜迪（BYD）と日産の研究所」かもしれない。これは皮肉ではなく、**忘れられた長文がどう次の時代に届くかの実例**です。

そしてその文書が読み返されるかどうかは、もはやエンジニアの英語力ではなく、**LLMにどう問いを投げるか**で決まる時代になりました。

これが**AI考古学**です。
