## 2. 核心：『適格性壁 (c) 政府契約による公開強制』の構造

### (b) ARPA 契約条項と公開強制構造

1969 年当時の ARPA 契約は、米国連邦調達規則（FAR/DFARS の前身）により **政府資金拠出成果物は公開を原則** とする条項を含んでいた。BBN は契約成果物として：

1. **BBN Report 1822『Specification for the Interconnection of a Host and an IMP』**（1969 年 4 月、Kahn 起草）を **公開技術仕様書** として ARPA に納入
2. ARPA はこれを **DDC（Defense Documentation Center、現 DTIC）** 経由で米国研究機関・大学に配布
3. 1971 年以降、Network Working Group が RFC（Request for Comments）プロセスを確立し、**RFC 系統に統合**
4. 1992 年 IETF が **Internet STD 39** として正式標準化

このプロセスにより、IMP 仕様・パケット交換アルゴリズム・ホスト-IMP プロトコルは **特許化される前に公開技術仕様書として確定** し、後発の特許出願は **prior art（先行技術）として拒絶される構造** が成立した。BBN Report 1822 は現在も **rfc-editor.org/in-notes/std/std39.txt** で全文公開されており、ARPA 契約構造の遺産として 57 年間アクセス可能な状態が続いている。

### (c) Kahn の TCP/IP 後継戦略との連続性

Kahn は IMP プロジェクト後、1973 年に Vint Cerf と TCP/IP を共同設計し、**1981 年 RFC 793『Transmission Control Protocol』** で公開。これも **DARPA 政府資金プロジェクト** であり、IMP と同じ『**政府契約 → 公開仕様 → IETF 標準化**』のパスを辿った。Kahn の TCP/IP も特許化記録が今回 verify 範囲で発見できず、Kahn の発明戦略は IMP 期から TCP/IP 期まで **政府契約による公開強制** を一貫して受け入れていたと観察できる。

### 著者の解釈

- 『適格性壁 (c) 政府契約による公開強制形態』は ep88 SW-002 FORTRAN『判例不在期 (a)』／Day 24 ep87 SW-005 HyperCard『判例 unsettled 期 (b)』との比較で抽出した事後的構造化で、**専門家から『そもそも 1969 年 ARPA 契約条項の知財扱いはハードウェアと文書で異なる』『IMP のソフトウェアは Trade Secret 扱いだった可能性』と突っ込まれる余地がある**
- 『Kahn の TCP/IP も同形態』は IMP→TCP/IP の連続性観察で、**Kahn 個人特許の網羅検証までは行っていない**

### この比較が破綻する点

- USPTO Patent Center 直接検索による BBN 名義 1969-1975 年期 IMP 関連特許の網羅取得は今回未実施。BBN は商業的に **言語処理・音響・数学ソフトウェア** で多数特許を取得した実績があり、IMP プロジェクト外で BBN が取得した特許群との切り分けが必要
- 『ARPA 契約条項により公開強制』は当時の標準的契約構造の一般論で、**1969 年 ARPA-BBN 契約書原本** の精査までは行っていない
- BBN Report 1822 を起草した Kahn 自身が、IMP のハードウェア構成（Honeywell DDP-516 改造部分）を BBN 名義で別途特許出願した記録は今回未取得。**ハードウェア部分の特許化は適格性壁の対象外** で、Lapson + 共同発明者 cursor control US4464652（SW-007）と同じく Claim 化に成功した可能性は残る
