## 発掘メモについて

一次資料 URL の存在を「会社の歴史的事実として」確認したが、**特許番号自体は Web 公開資料からは特定できなかった**。Day 22 引継ぎ (a) として「DPMA 直接検索」を実行したが、1900 年代初頭の DRP（Deutsches Reichspatent）は **DPMA DEPATISnet の網羅対象外**で、対話的検索 UI または紙アーカイブの直接照会が必要であることを発掘した。本メモは「**Lifschütz 1902 年特許の DRP 番号が情報壁の向こうにある**」という発見そのものを確定する化粧品 形態 3 情報壁第 2 弾。

| 項目 | Web 公開資料からの確認内容 |
|---|---|
| 発明者 | Isaac Lifschütz（1852 ピンスク生 - 1938 ハンブルク没） |
| 譲受人 | Lifschütz 個人 → 1911 年 Beiersdorf に売却（Oscar Troplowitz 取得） |
| 出願年 | **1900 年**（Beiersdorf 公式 Chronicle 12 PDF：「In 1900, he applied for a patent for this success today」） |
| 成立年 | **1902 年**（Beiersdorf 公式：「The patent was granted in 1902」） |
| タイトル | **「method of producing highly water-absorbent ointment bases」** |

| 一次資料 URL | DPMA 紙アーカイブまたは DEPATISconnect 対話検索（要 PC ブラウザ） |

## 2. 核心：DPMA 情報壁の構造

Day 22 引継ぎ (a) で「**DPMA 直接検索で Lifschütz 1902 DRP 番号を特定する**」アクションを取った。実行手順は以下：

```
[STEP 1] Web 公開資料の網羅
  - Beiersdorf 公式 About Us / Personalities / Lifschütz ページ
  - Beiersdorf 公式 Eucerin Brand History ページ
  - Beiersdorf 公式 Chronicle 12 PDF（5.7 MB、pdftotext で全文抽出）
  - Wikipedia 英 Eucerin
  - Wikipedia 独 Isaac Lifschütz
  - 独 Chemie-Schule Eucerit / Lifschütz エントリ
  - 独 PharmaWiki Wollwachsalkohole
  - 独 Jüdische Allgemeine「Der Doktor aus Pinsk」
  - 独 LinkFang・Grokipedia・DeWiki（Wikipedia 派生）
  - 独 Eucerit Wikipedia
  - Beiersdorf 公式 Markengeschichte Eucerin（独）
  - 独 Brennessel-München・Aliacura・Olionatura・Apothekenwiki（Wollwachsalkohol 専門サイト）

[STEP 2] DRP 番号の有無確認
  → 結果：上記 13 件いずれにも DRP 番号の記載なし
  → Beiersdorf Chronicle 12 PDF には「1) Patent number — This number precisely identifies the patent
    and allows it to be referenced at the patent office. Dr. Isaac Lifschütz laid the foundation for
    dermatological skin care with the patent for a method of producing highly water-absorbent ointment
    bases.」という解説（番号の概念紹介）はあるが、肝心の番号本体は本文に出てこない

[STEP 3] DPMA DEPATISnet 直接検索の試行
  - depatisnet.dpma.de の Expert Search UI へ WebFetch アクセス
  → UI HTML のみ取得、検索結果ゼロ（対話的入力必須、curl/WebFetch では検索送信不可）
  - Espacenet REST API（worldwide.espacenet.com）
  → HTTP 403 Forbidden（API キー必須、認証なしアクセス拒否）
  - Google Patents（patents.google.com）の inventor=Lifschütz / before=1903 検索
  → results: 0（1900 年代初頭の DE/DRP は Google Patents の DE カバレッジ外）

[STEP 4] AI 生成候補番号の実体検証
  - 検索 Engine で「DRP 132307」「DRP 154959」「DRP 171146」「Patentschrift 154959 Lifschütz」を WebSearch
  → 該当ヒットなし、Wollwachsalkohol 専門サイトに番号情報なし
  - patents.google.com で個別番号を curl
  → Captcha「Sorry... your computer or network may be sending automated queries」で全件拒否
  → AI（Search AI Overview）が生成した可能性のある候補番号は実体検証不能

[STEP 5] 情報壁確定
  → DPMA 紙アーカイブの直接照会（独・München の DPMA 本部または Berlin の Imperial Patent Office 後継組織）
  → または Beiersdorf 社アーカイブへの直接照会（Beiersdorf 広報・Beiersdorf Stiftung 経由）
  → が次アクションとして残る
```

## 3. 化粧品サブシリーズ DB 形態 3 情報壁の構造的特徴

化粧品サブシリーズの DB 信頼性問題 4 形態のうち、**形態 3 情報壁** は Day 22 ep80 CS-010 三省製薬コウジ酸（J-PlatPat 直接対話検索の壁）に続いて、本メモ CS-004 が **第 2 弾**となる。形態 3 情報壁の構造的特徴を整理する：

| 共通要素 | CS-010（コウジ酸、Day 22 ep80） | CS-004（Eucerit、本メモ Day 23） |
|---|---|---|
| 一次資料の存在 | 三省製薬・コーセー・厚生労働省の公開歴史で「1975 年発見・1988 年承認」が確認 | Beiersdorf・Wikipedia・独化学百科で「1900 年出願・1902 年成立」が確認 |
| 番号の不在 | J-PlatPat 公開公報番号（特開昭・特公昭）が Web 公開資料に未記載 | DRP 番号が Beiersdorf 公式 Chronicle 含め全 Web 公開資料に未記載 |
| 標準データベースの壁 | J-PlatPat（JS-heavy / authenticated） | DPMA DEPATISnet（対話 UI 必須）+ 1900 年代カバレッジ薄 |
| 国別 / 言語別 | 日本語（特公昭・特開昭の旧体系） | ドイツ語（DRP 旧体系、1900-1903 は電子化不完全） |
| AI 生成候補の検証不能 | JP S58-118507 = Lion Corp 透明歯磨（番号取り違え発覚） | DRP 132307/154959/171146 = WebSearch で全件ヒットなし |
| 次アクション | 三省製薬への直接照会または J-PlatPat 対話検索 | DPMA 紙アーカイブ照会または Beiersdorf 社アーカイブ照会 |

つまり **「歴史的事実は語られているのに、起点特許の番号だけが旧データベース体系の壁の向こうにある**」という構造が、コウジ酸（日本）と Eucerit（ドイツ）で **国を跨いで再現された**。化粧品 Phase 1 サブシリーズが扱う 19 世紀末-20 世紀初頭・1980 年代日本の特許群は、**この情報壁の構造的問題**に系統的にぶつかる可能性が高い。

## 4. 厳密にはこう（簡略 3 項目）

**確認済みの事実：**
- Beiersdorf 公式 Chronicle 12 PDF（5.7 MB、`https://www.beiersdorf.com/~/media/Beiersdorf/about-us/our-history/chronicle/2024/chronicle-12/Beiersdorf-chronicle-12-en-pdf.pdf`、pdftotext 抽出）に DRP 番号の本文記載なし。
- Wikipedia 英「Eucerin」、独「Isaac Lifschütz」、Chemie-Schule、PharmaWiki、Jüdische Allgemeine いずれにも DRP 番号未記載（2026-05-09 取得）。
- Lifschütz は生涯 20 件の特許を保有（独 Wikipedia「Lifschütz hielt 20 Patente」）が、Eucerit 1902 特許の番号は記載なし。
- DPMA DEPATISnet（`https://depatisnet.dpma.de/`）は対話的検索 UI のみで、curl/WebFetch では検索送信不可。
- Espacenet REST API は HTTP 403 Forbidden（認証必須）。
- Google Patents の 1900 年代初頭 DE 特許カバレッジは薄く、inventor=Lifschütz / before=1903 検索で 0 件。

**未確認：**
- DRP 番号本体（DPMA 紙アーカイブまたは Beiersdorf 社アーカイブ照会必須）。
- Lifschütz の他 19 件の特許の番号・タイトル・出願日。
- Beiersdorf が 1911 年に Lifschütz から購入した正確な金額・契約条件。

**この比較が破綻する点：**
- 「Eucerit 1902 年特許がニベアの起点」と書くと、**ニベア・クレーム自体は 1911 年に Troplowitz・Lifschütz・Unna の 3 人で開発した別製品**という事実を見落とす。Eucerit は emulsifier（乳化剤）であって、ニベア・クレームは emulsifier + 鉱物油 + 水の混合物。Eucerit 単独で「ニベアの起点」と語るのは過大評価。
- Lifschütz 1902 年特許のタイトル「method of producing highly water-absorbent ointment bases」は **薬学領域の軟膏基剤**であり、化粧品（cosmetic）として位置づけられたのは 1911 年 Beiersdorf 取得後の Troplowitz の商業判断。「化粧品サブシリーズ」に分類するのは AI 考古学の便宜であって、特許自体の領域は **製薬**。
- 「DPMA 情報壁」と書くと、DPMA が意図的に隠蔽しているような印象を与えるが、実態は **1900 年代初頭の DRP の電子化が不完全**で、紙アーカイブの相互参照システムが対話的検索 UI に集約されているだけ。情報壁は構造的なものであって、敵対的なものではない。
